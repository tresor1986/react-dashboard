# React Dashboard

A mini dashboard built with React + TypeScript + PrimeReact, featuring authentication and data management.

## Features

- Login page with form validation
- Protected routes (PrivateRoute guard)
- Data table with real-time client-side filtering
- Async data loading simulation
- Logout with session cleanup

## Tech Stack

- React 19 + TypeScript
- Vite
- PrimeReact + PrimeIcons
- React Router DOM

## Getting Started

npm install
npm run dev
